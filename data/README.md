# Data

This folder is the expected location for the data files used by the analysis and
plotting workflows for the Joule article:

Wan et al., "Managing silicon burn-out via onboard material diagnostics for
durable high-energy density batteries," *Joule* (2026).
https://doi.org/10.1016/j.joule.2026.102531

The full dataset is distributed separately on Zenodo:

https://doi.org/10.5281/zenodo.20259651

Download the data archive from the DOI above, unzip it, and place the extracted
contents in this `data` folder. After extraction, the repository should have the
following layout:

```text
managing_si_burnout_joule_repo/
├── code/
└── data/
    ├── cell_ocp/
    ├── cell_lifetime_data/
    └── bol_eol_crate_data/
```

All paths in the code are relative to the repository root, so no user-specific
absolute paths should be required after the data archive is extracted here.

## Folder Structure

After downloading and extracting the data archive, this folder should contain:

```text
data/
├── cell_ocp/
├── cell_lifetime_data/
│   ├── test_matrix.xlsx
│   ├── type1/
│   └── type2/
└── bol_eol_crate_data/
```

If the archive extracts as a top-level folder named `data`, move or merge its
contents into this repository-local `data` folder so that paths such as
`data/cell_ocp` and `data/cell_lifetime_data` exist directly under the
repository root.

## `cell_ocp`

Open-circuit-potential (OCP) reference files used to construct and fit the electrode-level model. The folder includes graphite, NMC622, silicon, reconstructed silicon, and composite-anode OCP inputs used by the MSMR identification, diagnostic, and plotting workflows.

Key files include:

- `Graphite_OCP_Lithiation.csv`
- `Graphite_OCP_Lithiation_raw.csv`
- `NMC622_OCP_Delithiation.csv`
- `Silicon_OCP_Lithiation_verbrugge.csv`
- `Silicon_OCP_Lithiation_MSMR.csv`
- `Anode_OCP_Lithiation.csv`

`Graphite_OCP_Lithiation_raw.csv` provides the raw graphite lithiation OCP
reference in `sto,p` format for traceability. `Graphite_OCP_Lithiation.csv` is
the curated graphite OCP input used by the repository workflows unless a script
explicitly states otherwise.

## `cell_lifetime_data`

Processed lifetime cell data used by the cell-level diagnostic workflow and group-trend analysis. The file `test_matrix.xlsx` summarizes the experimental conditions, including cycling or calendar-aging mode, pressure, temperature, C-rate, SoC window, and cell IDs.

The cell folders are split into `type1` and `type2` because the Voltaiq export schema changed across the dataset. This split is a file-format distinction, not a scientific grouping. The diagnostic loader selects the correct schema from the cell ID.

Expected core files are:

- `type1/GMFEB23S_CELLxxx/CD.pkl.gz`
- `type1/GMFEB23S_CELLxxx/CCM.pkl.gz`
- `type2/GMFEB23S_CELLxxx/cell_data.pkl.gz`
- `type2/GMFEB23S_CELLxxx/cell_cycle_metrics.pkl.gz`

For `type1` cells, `CD.pkl.gz` contains the cell lifetime time-series data,
including current, voltage, temperature, capacity/throughput, protocol labels,
and test identifiers. `CCM.pkl.gz` contains the corresponding cycle-level
summary metrics derived from those time-series records.

For `type2` cells, `cell_data.pkl.gz` is the analogous lifetime time-series
file, while `cell_cycle_metrics.pkl.gz` contains the corresponding cycle-level
summary metrics. Some cell folders also include CSV exports of the cycle
metrics for easier inspection.

The current dataset contains all 60 cells listed in `test_matrix.xlsx`: 40 cells in `type1` and 20 cells in `type2`.

## `bol_eol_crate_data`

Charge-rate diagnostic data used for beginning-of-life (BOL) and end-of-life (EOL) C-rate analysis. These files support the crate diagnostic workflow and the sensitivity studies comparing silicon-OCP deformation, discarded initial charge data, and kinetic compensation.

## Notes For Users

- Do not edit the raw data files in place. The workflows write derived results to `code/.../batch_results`, `code/.../outputs`, or figure-specific output folders.
- Cache folders generated by the notebooks can be deleted and rebuilt.
- Temporary Excel lock files such as `~$test_matrix.xlsx` are not part of the dataset and should not be uploaded or committed.

## Dataset Context

This dataset accompanies the code repository for the Joule article "Managing silicon burn-out via onboard material diagnostics for durable high-energy density batteries" and provides the data required to reproduce the analyses and figures in that work.

The corresponding code package is available at:

https://doi.org/10.5281/zenodo.20259383

For updates and future releases, please see:

https://github.com/zhiwen-wan

The lifetime-aging trends represented by this dataset were previously analyzed in:

Wan, Zhiwen, et al. "Degradation and expansion of lithium-ion batteries with silicon/graphite anodes: Impact of pretension, temperature, C-rate and state-of-charge window." *eTransportation* 24 (2025): 100416.

That work discusses the degradation and expansion behavior across pretension, temperature, C-rate, and SoC-window conditions. The present repository uses the dataset to develop and demonstrate silicon/graphite material-specific diagnostic and current-share analysis workflows.
