# Figure 5

This folder contains the plotting scripts for the Figure 5 panels that are rendered
directly from saved diagnostic and CRB outputs.

- `F05_a_1_voltage_plot.m` plots BOL/EOL voltage and dV/dQ traces across C-rates.
- `F05_a_2_reverse_barplot_transitionSoC.m` plots the C-rate diagnostic errors, including transition-SoC error.
- `F05_b_sampling_point.m` plots the CRB error bounds versus sampling density.
- `F05_c_1_reversed_SpecialSoCWindow.m` plots representative SoC-window CRB error bounds.

The companion `F5_c_2` contour-map panel is generated in:

- `../../error_bound_analysis/F05_2_2_reversed_SpecialSoCWindow.m`

Figure 5 data are generated by:

- `../../error_bound_analysis`
- `../../diagnostic_algorithm_lifetime_crate/A04a_run_initial_charge_discard_si_ocp_study.py`
- `../../diagnostic_algorithm_lifetime_crate/A04b_evaluate_initial_charge_discard_si_ocp_study.py`

The scripts here avoid duplicating those data-generation workflows and only handle
the final figure rendering.
