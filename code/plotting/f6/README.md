# Figure 6

Figure 6 uses the lifetime diagnostic outputs generated by:

```text
../../diagnostic_algorithm_lifetime_crate/A01_cell_lifetime_diagnostics.ipynb
```

The calendar-aging day calculation also needs the raw lifetime data. The
complete lifetime dataset is expected at:

```text
../../../data/cell_lifetime_data
```

If a local data copy is intentionally incomplete, unavailable calendar-aging raw
data will be reported as `raw_missing_day_preserved`.

Run the Figure 6 workflow in this order:

1. `F6_add_calendar_day.ipynb`

   Appends the calendar-aging exposure time (`day`) to the lifetime summary
   CSV files in:

   ```text
   ../../diagnostic_algorithm_lifetime_crate/batch_results/A01_cell_lifetime_diagnostics
   ```

   Cycling cells keep `day = NaN`. For calendar-aging cells, `day` is computed
   from the raw lifetime data using the voltage and temperature conditions
   defined in the notebook.

2. `F6_new_framework_group_results_python.ipynb`

   Reads the lifetime summary CSV files, assigns each cell to the cycling and
   calendar-aging groups used in Figure 6, removes invalid low-capacity
   calendar-aging rows, resolves duplicate calendar-day entries by keeping the
   largest measured charge capacity, and writes:

   ```text
   F6_group_plots_outputs_html/Master_with_groups_and_day.csv
   F6_group_plots_outputs_html/CycleMaster.csv
   F6_group_plots_outputs_html/CalendarMaster.csv
   ```

   It also writes lightweight HTML previews for group-level checking.

3. `F6_cycle_trend.m`

   Generates the cycling-aging trend panel from
   `F6_group_plots_outputs_html/Master_with_groups_and_day.csv`.

4. `F6_calendar_trend.m`

   Generates the calendar-aging trend panel from
   `F6_group_plots_outputs_html/Master_with_groups_and_day.csv`.

5. `F6_2_TransitionSoC_map_coupled_deformation_fixed.ipynb`

   Generates the transition-SoC map with silicon-OCP deformation coupled to
   `C_n,Si`.

The MATLAB scripts write figure files to:

```text
figures
```
